# Code of Conduct

We are committed to a welcoming, harassment-free scientific software
community. Be respectful, accept constructive feedback, distinguish evidence
from interpretation, and focus criticism on ideas and implementations.

Harassment, personal attacks, discriminatory conduct, sexualized attention,
doxxing, and other behaviour reasonably considered inappropriate are not
accepted. Report concerns privately through the repository owner's GitHub
profile. Maintainers may edit or remove contributions and restrict
participation when necessary.

This policy is adapted from the Contributor Covenant, version 2.1.
